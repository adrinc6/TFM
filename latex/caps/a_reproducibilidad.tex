\chapter{Reproducibilidad}

La evidencia empírica procede del estudio \texttt{study-20260803-201234-b4d7a8d8} y del run ganador
\texttt{run-51e95a09a8f0}. El script
\texttt{latex/scripts/export\_study\_assets.py} regenera tablas e imágenes PNG a partir de los
artefactos persistidos. El fichero \texttt{latex/asset\_manifest.json} lista las fuentes de cada
salida. Para la compilación en Overleaf se debe seleccionar XeLaTeX y ejecutar Biber.
